Departments

三大部门
总有一个位置属于你

动手把东西做出来、把知识讲给更多人听、还是站在全局统筹一场活动—— 三条完全不同的成长路径，通向同一个地方。

Maker

创客部

让奇思，落地成真。

集编程、机器人、电路设计、航模、手工为一体，专注科技产品创作。 这是社团里动手密度最高的部门，也是最多奇思妙想变成实物的地方。

日常在做什么 焊接电路、操控 3D 打印、调试程序、组装机器人与航模，筹备并举办创客比赛。
招牌活动 「飞鸟投林」「承鱼落稍」「宠物大赛」「木牛流马」——每年刷屏校园的爆款创客比赛。
能学到什么 Arduino / C / Python 控制、SolidWorks 三维建模、电路设计与焊接、结构搭建与调试。
适合谁 喜欢拆东西、爱折腾、脑子里总有个想做的玩意儿的人。零基础也可，培训从焊第一块板开始。
Science

科普部

把复杂的东西，讲得人人都能懂。

致力于向大众科普科学知识，日常撰写推文、举办讲座。 如果你表达欲强、审美在线，这里是你的主场。

日常在做什么 选题写科普推文、策划并主讲科普讲座、制作活动海报与宣传物料。
高光机会 每年拥有参加广东省科普讲解大赛的海选资格，直通省级舞台。
能学到什么 Premiere 剪辑、Photoshop / 海报制作、PPT 设计、文案写作，以及站在台上的表达力。
适合谁 喜欢写、喜欢讲、喜欢把知识安利给别人的人；也欢迎想练胆量、练口才的你。
Admin

常委部

社团的中枢神经。

负责通告与决定的发布、档案管理，辅助社团各项活动的举办。 一个部门决定整个社团跑得顺不顺。

日常在做什么 发布通知与决定、整理档案与活动资料、协调各部门排期、保障活动现场落地。
必备技能 Word / Excel / PowerPoint 办公软件三件套——也是你入社后会练到最熟的三件套。
能学到什么 项目统筹、跨部门沟通、文档与流程管理，这些能力在大学和社会里同样值钱。
适合谁 细心靠谱、愿意扛事、想锻炼组织协调能力的同学。
