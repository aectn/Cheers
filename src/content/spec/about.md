
# 关于奇思科创社

**奇思科创社（Cheers STEAM Club）** 是揭阳一中专注于科技创新的学生社团。我们相信，每一个奇思妙想都值得被认真对待、被亲手实现。

> [!NOTE]
> 我们用代码、开源硬件与机器人，把课堂之外的好奇心变成可以触摸的作品。

## 🚀 我们在做什么

- **机器人战队** —— 从机械结构、电控到算法，组队参加机器人竞赛，在赛场上迭代我们的设计。
- **编程与算法** —— 算法竞赛、Web 与小程序开发、自动化脚本，用代码解决真实问题。
- **开源硬件** —— Arduino / ESP32 / 树莓派，传感器、舵机与灯光，动手做出会动的东西。
- **创意项目** —— 不限主题：数据可视化、互动装置、校园工具，只要你想做，我们就一起搞。

## 🛠 你能获得什么

- 一群同样热爱折腾的伙伴，和一间可以深夜调代码的社团教室。
- 从 0 到 1 把一个项目做出来的完整经验：立项、分工、调试、展示。
- 面向比赛与作品的实战训练，以及学长学姐的复盘与带飞。

## 🤝 加入我们

招新季面向全校同学开放，零基础也欢迎——我们更看重你想不想做点东西。
